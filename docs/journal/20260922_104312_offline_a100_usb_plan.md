## 助手核对与回复要点

### 结论

只拷代码不够；无网 A100 上 `uv sync` 会访问 PyPI 直接失败，不能用。
正确做法是把代码（含子模块与 `.git`）、两份权重（约 18 GB）、
两个环境的离线 wheelhouse、uv 二进制一起放进 U 盘（exFAT/NTFS，不能 FAT32，
单文件 4 GB 限制，safetensors 每个 9 GB），在 A100 上用
`uv venv` + `uv pip install --no-index --find-links` 离线安装。

### 本机（/home/fusan/qiansai）只读核对结果

- `git submodule status`：两个子模块均未初始化（`-` 前缀），
  `third_party/chipmate` 与 `data/verilog_eval` 目录为空；
  本地直接拷代码会缺 ChipMATE 与 156 题数据集，须先
  `git submodule update --init --recursive`。
- `model/weights/` 仅含 `.gitkeep`；本地没有权重，18 GB 权重只在旧服务器
  （/root/autodl-tmp/qiansai，见 docs/guides/server_setup.md）。
- 本机工具：uv 0.9.13（文档固定 0.9.18，打包前建议先升到 0.9.18）、
  Python 3.12.3、iverilog/vvp 可用；磁盘空闲约 912 GB。
- 旧服务器数据盘 50 GB 已用 39 GB（2026-09-11 记录），在旧服务器上同时
  容纳 wheelhouse 与权重导出空间紧张，wheelhouse 建议在本机生成。

### 关键依据

- scripts/setup_cuda.sh 第 18、22 行：`uv sync --frozen` 与
  `uv pip install --index-url pypi.org` 均需网络。
- pyproject.toml：`chipmate-inference` 是 `third_party/chipmate` 的
  editable path 依赖，工作流环境安装本身需要子模块源码在场。
- scripts/prepare_data.py 依赖 `git -C data/verilog_eval rev-parse HEAD`，
  代码包必须保留 `.git`（含 `.git/modules`），否则数据准备失败。
- 旧服务器 `.venv-vllm` 是指向系统盘 /root/qiansai-envs/vllm-0.19.1 的
  符号链接且 venv 含绝对路径，按既有共识不跨机复制虚拟环境，
  离线时以 wheelhouse 重建。

### 推荐的分阶段方案（未实测，待执行）

1. 本机：升级 uv 至 0.9.18；补齐两个子模块；`uv export --frozen --no-hashes`
   导出工作流精确 pin（过滤 `-e` 行）；`pip download` 生成
   wheelhouse-workflow 与 wheelhouse-vllm（后者 `--require-hashes` 读
   docker/requirements.cuda.lock）；`uv build --wheel` 打包 qiansai 与
   chipmate 两个 wheel；整仓 tar（含子模块与 .git）。
2. 旧服务器：导出 model/weights tar 与 download_manifest.json，传回本机。
3. U 盘（≥64 GB，exFAT/NTFS）：代码包、权重包、两个 wheelhouse、
   workflow pin 列表、uv 0.9.18 静态二进制；可选按 A100 发行版
   `apt-get download iverilog` 备用。
4. A100：检查 python3.12/iverilog/vvp/nvidia-smi 与磁盘（建议 ≥80 GB 空闲）；
   解压代码；`uv venv` + `uv pip install --no-index --find-links` 离线装两个环境
   （vllm 环境带 `--require-hashes`）；`prepare_data.py` 重新生成
   data/processed；按 model/manifest.json 校验两份 safetensors SHA256
   （1e829e64…458826、8ac6cacb…64fb4d）；pytest → 3 道部署检查题 → 全量 156 题。
5. A100 显存更大，gpu_memory_utilization 0.45/服务须重新核算，
   不默认沿用即视为满足比赛 32 GB 约束。
