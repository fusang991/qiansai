## 用户原始输入

> 对，我能直接用新服务器连接旧服务器， 然后从旧服务器把数据直接拷贝到新a100上吗？
> 我的a100没有玩过的意思是连不了外网

## 助手回复要点

新 A100 能 SSH 连旧服务器时，U 盘与本地中转都不需要：旧服务器有外网，
负责生成离线 wheelhouse；代码、子模块、`.git` 和 18 GB 权重随工程目录
整体 rsync 到 A100。无网机器上 `uv sync` 仍不可行（scripts/setup_cuda.sh
第 18、22 行需访问 PyPI），A100 上以
`uv venv` + `uv pip install --no-index --find-links` 离线重建两个环境。

修订后的分阶段方案：

1. 旧服务器生成 wheelhouse（约 10–15 GB；数据盘 50 GB 已用 39 GB，
   空间不足时放系统盘 /root 下）：`uv venv --seed` 建下载环境；
   `uv export --frozen --no-hashes` 导出工作流精确 pin（过滤 `-e` 行）；
   `pip download` 两个 wheelhouse（vllm 环境带 `--require-hashes` 读
   docker/requirements.cuda.lock）；`uv build --wheel` 打包 qiansai 与
   chipmate 两个 wheel。
2. A100 拉取：`rsync -avP --exclude='.venv' --exclude='.venv-vllm'
   --exclude='runs' root@旧服务器:/root/autodl-tmp/qiansai/ /opt/qiansai/`
   加三个 wheelhouse/pins 传输；`-P` 支持断点续传，两端无 rsync 时改用
   tar over ssh。旧服务器 `.venv-vllm` 是系统盘符号链接，必须排除。
3. A100 安装：先检查 git、python3.12、iverilog、vvp、nvidia-smi
   （iverilog 缺失时用旧服务器同发行版 `apt-get download` 后 dpkg -i；
   uv 二进制从旧服务器拷贝）；离线装两个环境；`prepare_data.py` 重新生成
   data/processed；按 model/manifest.json 校验两份 safetensors SHA256；
   pytest → 3 道部署检查题 → 全量 156 题。

注意事项：数据集 revision 检查依赖 `git -C data/verilog_eval rev-parse HEAD`，
工程必须带 `.git`（含 `.git/modules`）整体传输；A100 建议预留 ≥ 80 GB；
验收通过前不删旧服务器 wheelhouse；SSH 凭据不写入仓库或文档；
A100 显存更大，gpu_memory_utilization 0.45/服务须重新核算，
不默认沿用即视为满足比赛 32 GB 约束。
