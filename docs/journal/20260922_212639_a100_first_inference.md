## 过程中的两个知识点

- `vllm/vllm-openai` 镜像 ENTRYPOINT 是 API server，直接传 `nvidia-smi`
  会被当成模型名；要跑它需 `--entrypoint nvidia-smi`。用户按此修正后
  GPU 检查通过。
- curl 首次 `connection reset by peer`：一次发生在服务未就绪时，
  改为看到 `Application startup complete.` 后重试；请求侧带
  `--noproxy '*'` 绕过可能存在的代理变量后成功。
